Create an API key and secret

MRR Mobile reads a Mining Rig Rentals account with an API key and secret that you create on their site. Paste that pair into the app. It is saved in the device secure store (the iOS Keychain or Android Keystore). The app developer never receives it.

1. Open API keys

Sign in at Mining Rig Rentals. If you do not have an account yet, register first. Creating an account is free.

Open API Key Management. From a signed-in account, open your username in the top bar, then API Keys.

2. Add a key

  1. Press Add A Key. The window title is Add New API Key. It does not ask for a name.
  2. Each permission is Write, Read, or None. A new key starts on None.
  3. Set Rigs to Write. That row is rig details and rig management.
  4. Set Rentals to Write. That row is rental browsing and rental actions.
  5. Leave Balance / Withdraw on None. That is the withdraw permission, and MRR Mobile leaves it off. Write on that row can request payouts.
  6. Press Save.

3. Copy the key and the secret

After you save, the page keeps the new key beside Key: and the secret beside Secret:. Both stay in the list. Copy both. In MRR Mobile, open Add account and paste them into API key and API secret.

Treat the secret like a password. Do not email it, post it, or put it in a shared note. If you delete the key, or the secret is no longer listed, create a new key and paste the new pair into the app. A deleted key stops working immediately.

What the app can see

With Rigs and Rentals set to Write, and Balance / Withdraw left on None, the app can show and update rigs and rentals. The key cannot request a payout while that row stays on None. Each request goes from your phone to Mining Rig Rentals. Signing uses the secret on the device.

On a key you already created, use the same settings and press Save Permissions.

Endpoint details are in the API v2 documentation. Mining Rig Rentals also publishes its own privacy policy and terms of service.
