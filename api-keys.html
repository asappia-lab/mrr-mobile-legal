Create an API key and secret

MRR Mobile uses a Mining Rig Rentals account with an API key and secret that you create on their site. Paste that pair into the app. It is saved in the device secure store (the iOS Keychain or Android Keystore). The app developer never receives it.

1. Open API keys

Sign in at Mining Rig Rentals. If you do not have an account yet, register first. Creating an account is free.

Open API Key Management. The page title is API Key Management. The same page is also under your username in the top bar, then API Keys.

Press the green Add A Key button.

2. Set every permission to Write

The window title is Add New API Key. It does not ask for a name. Each row starts on None. The choices are Write, Read, and None.

Click Write on all three rows, then press Save:

  • Balance / Withdraw — account balances, deposits, and withdrawals
  • Rentals — rental browsing and rental actions
  • Rigs — rig details and rig management

Write on every row lets MRR Mobile use the account completely, including payouts.

3. Copy the key and the secret

After you save, the new row stays in the list. Copy the value next to Key: and the value next to Secret:. Both stay on the page. The secret is not shown only once.

In MRR Mobile, open Add account and paste them into API key and API secret.

Treat the secret like a password. Do not email it, post it, or put it in a shared note. If you delete the key, create a new one and paste the new pair into the app. A deleted key stops working immediately.

On a key you already created, set the same three rows to Write and press Save Permissions.

What the app can do

With Write on Balance / Withdraw, Rentals, and Rigs, the app can show and update balances, rigs, rentals, pool profiles, and transactions, and it can request a payout. Each request goes from your phone to Mining Rig Rentals. Signing uses the secret on the device.

Endpoint details are in the API v2 documentation. Mining Rig Rentals also publishes its own privacy policy and terms of service.
