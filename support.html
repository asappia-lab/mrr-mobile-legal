Add an account

  1. On Mining Rig Rentals, open your username, then API Keys. Press Add A Key, set Rigs and Rentals to Write, and leave Balance / Withdraw on None. Press Save. The API key guide has the full page.
  2. In MRR Mobile, open Add account and paste the key and secret. They stay in the device secure store.
